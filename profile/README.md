# Important Notice: ant-design-blazor repository temporarily unavailable

**October 12, 2026**

To our community,

We want to inform you that the main repository,
[ant-design-blazor/ant-design-blazor](https://github.com/ant-design-blazor/ant-design-blazor),
has been temporarily disabled by GitHub Staff due to an alleged violation of
GitHub's Terms of Service.

We take this situation very seriously and are actively working to resolve it:

- **Appeal submitted**: We have submitted an appeal and reinstatement request
  through GitHub's official process to review the decision.
- **.NET Foundation support**: As an official .NET Foundation member project,
  we have also engaged the Foundation for guidance and advocacy.
- **Investigation**: We are reviewing recent activity in the repository,
  including some suspicious bot-submitted pull requests we noticed shortly
  before the disablement, and will take any necessary corrective action.

We firmly believe this project — a set of enterprise-class UI components based
on the Ant Design specification and Blazor, developed and maintained by a
global community since 2018 — complies with GitHub's Terms of Service, and we
are confident this issue will be resolved.

## Temporary backup repository
While the GitHub repository is under review, we have set up a temporary backup
repository on Gitee:

**https://gitee.com/ant-design-blazor/ant-design-blazor**

You can browse the source code and submit issues there. Please note that pull
requests are not supported in the backup repository for now; we will re-enable
contributions once the GitHub repository is restored.

## What remains available
- The official documentation site https://antblazor.com and the NuGet package
  `AntDesign` are unaffected and remain fully available.
- Our Discord community stays open for discussion and support.
- We will post updates here as soon as we hear back from GitHub.

## If your fork is affected
Some user-created forks may also have been disabled together with the original
repository. If your fork was affected, please contact GitHub Support directly
to request restoration of your own repository.

Thank you for your continued trust and support. We will keep the community
updated.

— The ant-design-blazor maintainers
